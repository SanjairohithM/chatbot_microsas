Quick Installation Guide

  1. Download the plugin ZIP file
  2. Go to WordPress Admin → Plugins → Add New
  3. Click "Upload Plugin" and select the ZIP file
  4. Install and activate the plugin
  5. Go to OmniX Chatbot → Settings to configure
  6. Generate access tokens in OmniX Chatbot → Access Tokens
  7. Use shortcode [omnix_chatbot bot_id="YOUR_BOT_ID" access_token="YOUR_TOKEN"]
[omnix_chatbot bot_id="47" access_token="YOUR_ACCESS_TOKEN_HERE" theme="default" position="bottom-right" auto_open="false" show_avatar="true" show_title="true" enable_voice="true" voice_language="en-US" auto_speak="false" ]

📋 Requirements

  • WordPress 5.0 or higher
  • PHP 7.4 or higher
  • HTTPS (required for voice features)
  • Modern web browser
